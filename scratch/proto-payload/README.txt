WHAT THIS IS

This disc is one of a numbered series that together hold a backup of
{archive name}. The files on it are ordinary files. You do not need any
special software to read them: open the folders and copy what you want.

The highest-numbered disc you have is the most up to date. Its
_ARCHIVE_INFO folder describes every disc in the series, including this one.

For notes about the photos themselves -- what the folders mean, how they were
organised -- see _ARCHIVE_INFO\about-this-library.


GETTING EVERYTHING BACK

1. Make an empty folder on a hard drive with plenty of space
   (about {2.4 TB} as of this disc).
2. Put in disc 1. Copy everything on it into that folder.
3. Do the same with disc 2, then 3, and so on, IN NUMBER ORDER, up to the
   highest-numbered disc you have.
4. When Windows asks whether to replace files that already exist, choose
   "Replace the files in the destination". Later discs hold newer versions.

You now have every file, as of the newest disc. Some things to expect:

- Files that were deleted or moved after an early disc was burned will still
  be there, at their old location. Nothing is lost; there is just some extra.
- Files that were renamed or moved to another folder after they were first
  burned come back under their OLD name and folder. The content is all there;
  only the organisation is older. INDEX.csv shows each file's current name
  and, in the "stored_as" column, the name it has on the disc.
- A file that was copied to a second place after it was first burned only
  comes back at the first place. INDEX.csv lists both.
- The copy will take up more space than the discs seem to hold. Identical
  files are stored once on a disc but appear in several folders; copying
  them to a hard drive writes each one out in full.
- You can skip copying the _ARCHIVE_INFO folder from every disc but the last.


GETTING ONE FILE OR FOLDER BACK

Open _ARCHIVE_INFO\FOLDERS.txt on the newest disc. Find the folder you want;
it lists the discs that hold its files. Copy that folder from each of those
discs, in number order.

For a single file, open _ARCHIVE_INFO\INDEX.csv (Excel, or Notepad -- it is
large, give it a minute) and search for the file name. The "disc" column says
which disc it is on.


IF A DISC WON'T READ

Try another computer or another Blu-ray drive first. Clean the disc with a
soft cloth, wiping from the centre outwards.

Every disc carries extra error-correction data. A disc that is scratched or
starting to fail can often still be recovered with the program dvdisaster,
which is in _ARCHIVE_INFO\tools on every disc. It is a technical tool; if you
are not comfortable with it, find someone who is and show them this file.

  For whoever is helping: the ECC is RS02, appended to the image beyond the
  end of the ISO filesystem. Read the whole device, not just the filesystem:
  dvdisaster -r --dao --ignore-iso-size, then -f to repair.
  The manual is in _ARCHIVE_INFO\tools.

If a disc is lost or can't be recovered, everything else is still readable.
INDEX.csv lists exactly which files were on the missing disc. Some of them
may also exist on a later disc.


FILE NAMES ON WINDOWS

Windows shows at most 103 characters of each file or folder name. Longer
names are cut short on Windows but are complete on Linux and macOS. INDEX.csv
always has the full name.


TECHNICAL DETAILS

Format: ISO 9660 with Rock Ridge and Joliet, plus RS02 error correction.
_ARCHIVE_INFO\archive.sqlite is the full database (SQLite), including the
history of every earlier snapshot. On this disc it describes all discs up to
and including this one; this disc's own entry is not yet marked verified,
because the database was written before the disc was burned.
INDEX.csv: one row per file in the library as of this disc. Hashes (blake3)
are in the database.
